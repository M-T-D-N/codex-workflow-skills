# Pink Elephant Guard

폐기된 과거안의 문구·논리·구조·라벨·프롬프트가 확정된 결과에 되살아나는 것을 막는다. 사용자 대면 산출물과 외부 수신자에게 넘길 확정 지시문에 적용할 수 있다. 일반 요약, 기억 관리, 도메인 편집과 전달 자체를 대신하지 않는다.

## 적용 조건

다음 조건을 모두 만족할 때 사용한다.

1. 현재 대화나 허용된 회수 문맥에 폐기·삭제·정정된 개념이 있다.
2. 사용자에게 제시하거나 대화 밖 수신자에게 넘길 확정 산출물·실행 지시문이 필요하다.
3. 재구성할 부분에는 변경 이력이나 과거안 비교가 필요하지 않으며, 필요한 운영 맥락은 보존할 수 있다.

다음 부분에는 적용하지 않는다.

- 비교·감사·디버깅·원인 분석·재개 인계에서 필요한 경위, 실패 증거, 복구 근거와 변경 기록
- 현재 유효한 승인 범위, 금지 조건, 불확실성, 마이그레이션·하위 호환성·규정·안전 고지
- 그대로 전달해야 하는 인용·로그·계약·코드·명령·식별자·경로·정형 데이터와 고정 payload
- 현재 확정 상태가 충돌하거나 결과를 바꿀 정도로 미해결인 부분
- 기억 정리·삭제 또는 재분류
- 일반 코드 변경. 단, 사용자가 변경 이력 없는 최종 재구현을 명시했고 과거 상태가 계약·테스트·마이그레이션에 필요하지 않은 경우는 예외로 한다.

## 현재 상태와 적용 부분

현재 사용자 요청과 적용되는 최신 authority를 우선한다. 회수된 기억과 과거 대화는 후보 문맥이며 현재 근거보다 우선하지 않는다. 실질적 충돌은 현재 근거로 확인하고, 결과를 바꾸는 불확실성이 남을 때만 핵심 질문을 한다.

작업 중에만 다음을 구분한다. 별도 파일이나 영속 기록은 만들지 않는다.

- `TARGET_STATE`: 현재 확정된 요구와 사실
- `REJECTED_HISTORY`: 폐기된 문구·논리·구조·라벨·프롬프트
- `VISIBLE_EXCEPTIONS`: 정확성·승인·계약·안전·접근성을 위해 보존해야 하는 현재 내용
- `SURFACE`: 이번에 현재 확정안으로 재구성할 부분. 인계문이나 메시지 전체로 자동 확대하지 않는다.

## 재구성 절차

1. `TARGET_STATE`의 필수 내용으로 임시 Clean Brief를 만든다. 현재 유효한 금지 조건과 승인 제한도 보존한다.
2. 폐기안을 되뇌는 지시 대신 현재 상태 자체를 명시한다. 필수 제한을 지우거나 사실·명령의 의미를 바꾸면서 긍정형으로 만들지 않는다.
3. Clean Brief에서 오염된 `SURFACE`를 새로 구성한다. 비오염 내용과 적용 밖의 운영 근거·정확한 원문은 보존한다. 변경 범위는 사용자 요청과 도메인 스킬의 편집 경계를 따른다.
4. 결과를 한 번 점검해 과거안의 직접 문구·동의 표현, 과거안에만 필요한 비교 구도·구획·라벨·자리표시자·프롬프트 구조가 남았는지 확인한다. 시각·청각 흔적은 실제 미디어를 검사한 경우에만 판단한다.
5. 누출이 있으면 Clean Brief에서 해당 부분을 한 번 재구성한다. 새 근거 없이 검사를 반복하지 않는다.

필수 고지와 사용자가 요구한 현재 예외는 숨기지 않는다. 필요한 현재 내용만 남기고 불필요한 과거 서사는 덧붙이지 않는다.

## 인계·외부 전달과 함께 쓸 때

- `prepare-codex-handoff`가 설치되어 적용되는 경우 수신자가 필요한 맥락과 전달 준비를 맡고, 이 스킬은 지정한 확정 산출물·실행 지시문 부분만 정리한다. 둘을 같은 작업에 사용할 수 있지만 인계 전체의 역사 삭제로 확대하지 않는다.
- 제목이나 문단을 나누어도 수신 모델은 전체 내용을 읽을 수 있다. 불필요한 폐기안은 전달문 다른 부분에서도 반복하지 않는다. 필요한 실패·복구·승인 이력은 충실히 보존하고 이 스킬의 재작성 대상에서 제외한다.
- 수신 대화에 이미 있는 과거 문맥을 지웠다고 주장하지 않는다. 새로운 확정 지시문의 준비와 수신 모델의 실제 이행을 구분한다.
- 문서·이미지·코드 등 도메인 스킬은 내용과 매체 품질을 소유한다. 이 스킬은 기억을 쓰거나 삭제하지 않으며, 새 대화·위임·전송 권한을 부여하지 않는다. 실제 전달은 사용자 승인과 해당 도구의 규칙을 따르는 작업이 맡는다.
- 사용자가 요청한 결과 외의 파일·설정·외부 상태를 변경하거나 Clean Brief·점검표를 파일로 남기지 않는다.
