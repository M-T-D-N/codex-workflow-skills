# Skill Usage Review

실제 사용 근거로 스킬의 선택 경계와 작동을 평가한다. 스킬 파일을 읽은 횟수와 유용하게 작동한 횟수를 구분하고, 필요한 가장 작은 변경을 권고한다. 검토 요청 자체는 읽기 전용이며 수정·설치·공개는 현재 승인된 범위를 따른다.

## 범위와 원본

- 대상 스킬의 실제 설치본, 비교할 배포본, 관련 참조와 적용 지침을 확인한다. 마지막 수정 이후를 요청받았다면 관찰 기준 버전과 종료 시점을 먼저 고정한다. 파일 수정 시각은 버전 증거와 구분하며, 과거 버전을 복원할 수 없으면 인과 판단의 한계를 밝힌다.
- 승인된 관련 기록의 위치와 형식을 확인한다. 일반 기록·보관 기록·압축 기록·작업자 기록 중 존재하는 경로를 고려하고, 선택한 범위와 접근 실패·미확인 범위를 남긴다. 일부 검색 결과를 전체 이력으로 부르지 않는다. 전체 검토 요청이 없으면 판단에 필요한 범위부터 읽고 조사 경계를 정한다.
- 이미 확보한 원본과 도구 결과를 재사용한다. 대량 기록은 좁은 후보 검색 후 필요한 요청·호출·반환·결과를 읽는다. 도구 이름에만 읽기 동작이 표현된 호출도 고려한다. 제공되지 않는 비공개 추론이나 암호화된 입력을 복원하려 하지 않는다.

## 실제 적용 판정

- 카탈로그 주입·단순 언급, 파일 읽기, 적용 선언, 적용 후 철회, 실제 적용과 결과 미확인을 구분한다. 읽기나 선언만으로 실제 발동·성공을 확정하지 않는다. 스킬 작성·감사·백업 중의 참조는 운영 적용과 별도로 센다.
- 실제 소스 파일·대화·턴·이벤트와 시각을 연결한다. 작업자 기록에 상속된 부모 ID나 요청을 현재 작업자의 직접 입력으로 오인하지 않는다. 위임 범위와 선후 관계를 원문으로 확인하고, 입력이 없으면 무단 적용이나 적절한 적용으로 단정하지 않는다.
- 같은 사건이 여러 파일·후속 턴에 나타나도 중복 완료로 세지 않는다. 원래 요청, 적용 시점, 실제 수행과 최종 결과를 연결하며 결과가 없거나 관찰 창 밖이면 그대로 미확인으로 둔다. 현재 검토가 만든 읽기·위임은 기존 사용 통계에서 제외한다.
- 선택 적합성, 절차 준수, 산출물 품질, 권한·부작용, 사용자 수정과 재작업을 관련 범위에서 따로 평가한다. 형식 검증·도구 성공·완료 선언을 실제 작업 성공으로 대신하지 않는다. 서로 다른 버전·기간·작업 표본의 횟수만으로 품질·속도·비용을 비교하지 않는다.

## 변경과 대안 판단

- 관찰된 문제를 선택 설명의 모호함, 본문 누락·충돌, 실행상 누락, 도구·환경 실패와 원인 미확인으로 나눈다. 규칙이 이미 있다는 이유만으로 충분하다고 결론내리지 않는다. 반복된 누락이면 읽는 순서·가시성·상충 지시·수용 기준과 연결되는지 확인한다. 반대로 실패마다 금지 문구를 추가하지 않는다.
- 필요한 경우 유지, 설명 축소, 본문 재배치·참조화, 기존 스킬과의 통합·분리, 새 스킬을 비교한다. 같은 문제를 해결하는지, 자동 선택 경계·권한·독립 설치·유지보수에서 무엇을 얻고 잃는지 판단한다. 단순히 함께 읽혔거나 사용 횟수가 적다는 이유로 합치지 않는다.
- 새 스킬은 기존 소유자가 없는 반복 가능하고 구별되는 업무가 있을 때만 제안한다. 기존 흐름의 일반 규율을 다시 포장하거나 모든 작업을 통과시키는 라우터·감사 단계를 만들지 않는다. 자동 선택 설정 변경은 현재 사용자 의사와 호스트의 지원 범위를 따른다.
- 중요한 변경은 근거, 왜 필요한지, 최소 수정 방법, 반례와 잃는 기능, 적절성·검증 한계 순서로 확인한다. 실제 사례와 다른 경계 사례를 함께 대조하되, 같은 문구를 되읽거나 합성 사례를 통과한 것을 실사용 개선으로 보고하지 않는다.

## 결과와 반영

스킬별 유지·변경 판단과 결정적 원본 위치, 확인한 범위와 남은 불확실성을 간결하게 제시한다. 큰 검토에서 재개가 필요하고 기록 쓰기가 현재 승인된 경우에만 기존 작업 기록에 후보·판정·근거 위치를 남긴다. 그 밖에는 응답·기존 도구 로그를 사용하며 원시 대화 복제, 고정 보고서나 새 기록 체계를 요구하지 않는다.

변경이 승인된 경우 실제 소유 정본을 수정하고 영향 범위를 직접 검증한다. 설치본·배포본 반영은 사용자가 승인한 대상과 순서를 따른다. 개인 전역 지침에 의존하는 필수 의미는 공개 스킬과 포함 참조에 담고 개인 경로·원시 이력·전용 인프라는 제외한다. 공개본의 형식·참조 검증과 실제 호스트에서의 선택·효과 검증을 구분한다. 요청한 수용 조건을 충족하면 새 검토 과제를 만들지 않고 종료한다.
