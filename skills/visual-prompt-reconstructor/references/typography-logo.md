# Typography and Logo

Use this reference when lettering, a wordmark, a logo, or designed text materially affects the image.

## Transcribe first

Separate literal text from visual style. Preserve line breaks, case, punctuation, symbols, and visible misspellings. Mark ambiguous characters as alternatives and unreadable material as illegible; do not silently repair it.

Distinguish primary designed text from incidental labels, watermarks, signatures, and decorative pseudo-lettering. Do not silently add or remove any of them.

## Observe design

- Letter skeleton, width, weight, stroke contrast, serif/sans construction, terminals, counters, joins, corners, and curvature.
- Custom ligatures, cuts, stencil gaps, distortion, perspective, baseline behavior, and character substitutions.
- Tracking, kerning, line spacing, alignment, hierarchy, orientation, and text-to-symbol proportions.
- Fill, outline, stroke layers, shadow, glow, gradient, bevel, emboss, extrusion, reflection, transparency, and texture.
- Material impression such as ink, paint, matte polymer, metal, glass, acrylic, neon, or printed foil.
- Negative space, enclosing shapes, badge geometry, symbol balance, and background contrast.

Do not name an exact font unless the file, metadata, or reliable provenance establishes it. Describe its construction and closest design category instead.

## Compile

Place the exact rendered string in quotation marks and state that it must remain case-sensitive. Keep the string identical in Korean, English, Japanese, and Chinese prompt variants. If spelling fidelity is critical, note that separate typesetting or vector finishing may be more reliable than image-model text rendering.

For known brands or IP, use a name only when the user supplied it or the mark is clearly legible. Do not imply official affiliation or ownership.
