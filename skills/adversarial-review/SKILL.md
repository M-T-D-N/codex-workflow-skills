# 목적

현재 결론을 무조건 공격하거나 새로운 문제를 만들어내지 말고,
사용자의 실제 의사결정이나 다음 목표를 바꿀 수 있는 결함만 찾는다.

문제의 틀 자체가 잘못되었을 가능성이 있을 때는 재개념화를
선행할 수 있지만, 새로운 틀도 기존 결론과 같은 기준으로 검증한다.

# 검토 대상

가장 최근에 취합·정리된 결론, 계획, 설계 또는 권고안을
주된 검토 대상으로 사용한다.

이전 대화는 다음 목적으로만 참조한다.

- 취합 과정에서 빠진 중요한 사실 확인
- 현재 결론과 원래 사용자 의도의 충돌 확인
- 서로 모순되는 관찰이나 결정 확인
- 근거가 실제로 존재하는지 확인

전체 대화를 다시 요약하는 작업으로 확대하지 않는다.

# 검토 방식 선택

항상 적대적 검토를 수행한다.

다음 중 하나 이상이 근거와 함께 확인되고,
재개념화가 최종 의사결정이나 목표를 실질적으로 바꿀 가능성이
있을 때만 재개념화를 선행한다.

- 여러 구성요소에서 동일한 근본 문제가 반복된다.
- 예외, 우회책 또는 보완 계층이 계속 누적된다.
- 결론이 검증되지 않은 문제 구분이나 경계에 의존한다.
- 개별 해결책은 타당하지만 전체 운용 흐름이 일관되지 않는다.
- 사용자 목표보다 기존 구조의 보존이 결론을 지배한다.
- 다른 문제 정의가 더 단순한 해결책으로 이어질 가능성이 있다.

주제가 복잡하거나 장기 프로젝트라는 이유만으로 재개념화하지 않는다.
새 용어, 계층 또는 프레임을 만드는 것 자체를 개선으로 취급하지 않는다.

# 재개념화가 필요한 경우

1. 기존 결론을 기준안으로 보존한다.
2. 실질적으로 다른 대안 프레임을 최대 하나만 만든다.
3. 대안이 필요한 구체적 근거를 제시한다.
4. 기존안과 대안을 동일한 검토 기준으로 비교한다.
5. 재개념화안이 우월하지 않으면 기존 결론을 유지한다.

사용자가 재개념화만을 별도로 요청하지 않은 한,
재개념화만 수행하고 검토를 종료하지 않는다.

# 적대적 검토 기준

현재 결론에서 의사결정이나 목표를 바꿀 수 있는 항목만 검토한다.

- 핵심 사실과 근거가 실제로 확인되었는가
- 최신 확인이 필요한 사실을 기억이나 추정으로 확정했는가
- 결론을 지탱하는 숨은 전제가 있는가
- 실제 반례나 상충하는 근거가 있는가
- 더 단순하고 직접적인 대안이 있는가
- 해결책이 원래 요청보다 범위를 확대하는가
- 실패 영향과 복구 가능성을 적절히 평가했는가
- 실행 환경과 사용자 제약에서 실제로 가능한가
- 이미 검증된 사실을 근거 없이 다시 의심하고 있는가

항목을 채우기 위해 약한 결함을 만들지 않는다.
추측성 가능성만으로 현재 발생한 문제처럼 표현하지 않는다.
중요하지 않은 사소한 흠을 핵심 반론처럼 부풀리지 않는다.

확인할 수 없는 내용은 사실로 채우지 말고
사실, 관찰, 추론, 가정, 권고안을 구분한다.

# 판정

다음 중 가장 근거에 맞는 판정을 내린다.

- 유지: 현재 결론이 검토를 견딘다.
- 부분 수정: 핵심 방향은 유지하되 특정 전제나 범위를 수정한다.
- 재구성: 문제 틀을 바꾸는 편이 실제로 더 낫다.
- 기각: 핵심 결론을 지탱하는 근거가 부족하거나 반증된다.
- 판단 보류: 중요한 근거가 없어 현재 결론을 확정할 수 없다.

문제가 발견되지 않았다면 억지로 수정안을 만들지 말고
현재 결론이 적대적 검토를 견뎠다고 명시한다.

# 출력

다음 내용을 필요한 것만 포함하여 작성한다.

1. 검토 방식

   - 직접 적대적 검토
   - 재개념화 후 비교 검토

   선택 이유는 한두 문장으로 설명한다.

2. 유지되는 핵심 결론

3. 수정·기각해야 할 내용

   실제로 중요한 항목이 없으면 생략한다.

4. 최종 판정과 수정된 최종 결론

5. 결론을 바꿀 수 있는 미확인 사항

   존재할 때만 포함한다.

고정된 개수의 문제점이나 반론을 만들지 않는다.
관련 없는 체크리스트나 후속 단계를 추가하지 않는다.

# 경계

기본적으로 읽기 전용이다.

사용자가 별도로 요청하지 않은 경우 다음을 수행하지 않는다.

- 코드나 문서 수정
- 새로운 목표 작성
- 구현 착수
- 파일 또는 계획 덮어쓰기
- 인접한 개선 작업 추가

검토는 근거 있는 최종 결론으로 끝낸다. 목표 등록이나 실행은 별도로 요청받은 경우에만 수행한다.
